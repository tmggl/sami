تفاصيل الحقيبة التدريبية

وصف البرنامج

برنامج تدريبي متكامل يمكّن المتدربين من بناء وتطوير مواقع الويب باستخدام Python وأطرها الحديثة، ويجمع بين الجانب النظري والتطبيق العملي في مشاريع واقعية مع الاستفادة من أدوات الذكاء الاصطناعي. يبدأ المسار من أساسيات البرمجة وبيئة Visual Studio Code، ثم الواجهات الأمامية HTML وCSS وJavaScript، وربطها بالواجهة الخلفية عبر Django، وصولًا إلى نشر المشاريع وفق ممارسات بيئة الإنتاج.

الهدف العام للبرنامج

تمكين المتدربين من بناء مواقع ويب احترافية متكاملة باستخدام Python وDjango، من أساسيات البرمجة والواجهات وقواعد البيانات إلى أدوات الذكاء الاصطناعي والنشر والأمان، بما يؤهلهم لتطوير حلول قابلة للتطبيق في سوق العمل.

  4. تثبيت وإعداد VS Code ولغة Python.

  6. إتقان أساسيات HTML وCSS وJavaScript.
  7. تنفيذ مشروع واجهة أمامية تفاعلي.
  8. تقسيم الصفحات وإنشاء روابط التنقل.
  9. إنشاء حساب GitHub وإدارة الإصدارات.
  10. نشر أول موقع ثابت عبر Render.
  11. التعرف على صفحات الهبوط.

  13. التعرف على إطار Django للواجهة الخلفية.
  14. فهم هيكلة Django وآلية MVT.
  15. تحليل هيكلة المشاريع بأدوات الذكاء الاصطناعي.

  17. بناء التطبيقات والنماذج ولوحة التحكم.

  21. التعرف على SQL وقواعد بيانات الإنتاج.
  22. ربط Cloudinary لتخزين الملفات.
  23. إرسال الرسائل الفورية عند التسجيل والمهام.
  24. نشر مشروع Django على Render.
  25. معالجة أخطاء النشر الشائعة بمساعدة الذكاء الاصطناعي.
  26. تحليل الأخطاء وتسريع حلها.

  28. التعرف على أهم مكتبات Django.
  29. تنفيذ اختبار عملي لبناء مشروع متكامل ونشره.

  • المعرفة الأولية بالبرمجة مستحسنة وليست إلزامية.
  • القدرة على قراءة المصطلحات الإنجليزية التقنية البسيطة.
